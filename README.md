# Театральная система — версия 2

Полная версия Windows Forms для управления театрами, режиссёрами, актёрами, спектаклями, зрителями, билетами и оценками в Microsoft Access.

Откройте `TheaterVersion2.sln` в Visual Studio, выберите запускаемым проектом `Theater.Version2` и нажмите F5. Требуются .NET Framework 4.8 и Microsoft Access Database Engine (ACE) x64. База данных: `Database\Театр.accdb`.
